{% comment %} The card for anonymous-facing pages: mvp's with the site logo above the slot. The logo is mvp's own , which resolves the project's asset and sizes it to the card. It used to be a hand-built with a fixed height class, which only rendered because this package shipped a stylesheet of its own containing that class. `size` is the width the page wants, passed straight to : sm, md, lg, xl, 2xl, 3xl or 4xl, or "full" for a card that fills its container. It defaults to 2xl, the width these pages have always rendered at, so a page that declares nothing is unaffected. A value outside that scale falls back to the default instead of reaching the markup. django-mvp's stylesheet carries only the widths its own component names, so an invented one would be a class that styles nothing: a card a little wider than the page asked for, with nothing to show why. {% endcomment %} {% with scale="sm md lg xl 2xl 3xl 4xl full" %} {{ slot }} {% endwith %}
