The wrapper carries `prose`, which is what styles the bare inline tags allauth emits inside paragraph copy — the "sign up"/"sign in" link in the login and signup intros, for one. Those arrive inside a blocktranslate, so there is no way to put a class on the anchor itself, and Tailwind's preflight would otherwise leave them looking like plain text. `prose` comes from django-mvp's stylesheet and takes its colours from the active theme, which is also where the body colour below comes from. This package used to ship a rule of its own for both. {% endcomment %}
